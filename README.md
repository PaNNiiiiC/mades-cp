# MADES Competitive Programming Contests

This repository contains the competitive programming problem sets, editorials, and reference solutions deployed for the Marmara University Developer Society (MADES) beginning in April 2026. 

## Repository Architecture

The repository is structured to separate administrative curriculum from chronological contest materials.

* `general_resources/`: Contains standard operating procedures and technical guides, including the MADES standard I/O and general rules manual and the CP beginner's guide.
* `MADES Algorithm Program Spring Qualifications/`: Contains problem statements and editorial for the algorithm program qualifications practice contest.
* `MADES Programing Challenge 25-26/`: Contains problem statements and editorial for the MADES Programming Challenge 25-26.
